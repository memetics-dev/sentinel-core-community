# Sentinel Core Public Preview Frontend

This trimmed frontend package contains only the public Community Preview routes and shared components needed to present Sentinel Core in a safe, simulated way.

Included routes:
- `/public`
- `/public/scenarios`
- `/public/scenarios/[scenarioSlug]`
- `/public/installation`
- `/public/onboarding-preview`
- `/public/deployment-preview`
- `/public/market-readiness`
- `/public/mobile-preview`
- `/public/community-preview`
- `/public/request-pilot`

No live internal ops-console routes are included in this export package.
