# Community Contribution Guide

## Useful Contributions
The most helpful Community Preview contributions are:
- docs clarity
- installer ergonomics
- hardware notes
- scenario feedback
- UI polish

## Contribution Boundaries
Please avoid contributions that push Sentinel Core toward:
- broad unsupported integrations
- cloud surveillance features
- alarm-company replacement claims
- hype-driven product framing

## Contribution Intent
Community Preview contributions should improve clarity, safety, repeatability, and operational learning rather than widen product promises prematurely.
