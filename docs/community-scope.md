# Community Scope

## Included
The Community Preview includes:
- Edge Core local runtime
- ops console
- public product and demo pages
- installer MVP scripts
- scenario scripts
- trial review tools
- documentation

## Not Included
The Community Preview does not include:
- production mobile app
- universal hardware support
- cloud account system
- managed monitoring
- certified alarm-company replacement
- production installer or image flashing workflow

## Commercial Boundary
Sentinel Core retains commercial positioning. Community Preview access does not imply that all future product capabilities, support models, or deployment packages are public or open.
