# Community Support Boundaries

## Support Expectations
Sentinel Core Community Preview does not guarantee support for arbitrary hardware, unsupported sensors, or unvalidated integration combinations.

## Safety Boundaries
Sentinel Core Community Preview should not be relied on for emergency or primary security decisions.
It is for controlled local testing and technical evaluation.

## Remote Service Boundary
The preview does not promise:
- remote monitoring
- managed cloud services
- account-based support tooling
- universal remote management

## Operational Boundary
This preview is intended to help developers and evaluators understand the system, not to claim finished household deployment readiness across all environments.
