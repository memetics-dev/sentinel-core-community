# Community Preview

## Purpose
This document explains what Sentinel Core Community Preview is, who it is for, and how it should be used responsibly.

## What Sentinel Core Is
Sentinel Core is a local-first residential intelligence system that interprets household activity through presence, rhythm, zones, progression, and response posture.

## Who This Preview Is For
This preview is intended for:
- developers
- edge-AI builders
- smart-home enthusiasts
- early technical evaluators

## What It Is Not
This preview is not:
- a production alarm replacement
- guaranteed prevention
- a managed monitoring service
- a certified alarm-company substitute

## How To Use It Safely
Use Sentinel Core Community Preview for controlled local testing first.
Start with simulated scenarios, then passive observation, then controlled real-world evaluation.
Do not rely on it as your primary household security system.
