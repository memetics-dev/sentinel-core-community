# Security and Responsible Use

## Responsible Use Boundary
Sentinel Core Community Preview is for controlled local testing, technical evaluation, and installation ergonomics review.

It is not:
- a production alarm replacement
- guaranteed prevention
- managed monitoring
- emergency-response infrastructure

## Reporting
If you identify a serious security issue in the exported preview package, do not publish exploit details blindly. Report the issue privately to the project maintainer before public disclosure.

## Operational Safety
- do not rely on this preview as your primary household security system
- do not assume support for arbitrary hardware or unsupported integrations
- do not assume remote monitoring or cloud-backed recovery
